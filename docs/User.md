# User & VR Headset Setup Guide

## Experiencing 3D Assets in WebXR

### 1. Meta Quest 2 / Quest 3 / Quest Pro
1. Open **Meta Quest Browser**.
2. Navigate to your project URL (e.g. `https://app.yourapp.com/project/clp123`).
3. Click the prominent **"ENTER VR MODE"** button.
4. Put on your headset to experience the 3D model in 6DOF immersive VR!

### 2. Apple Vision Pro
1. Open **Safari**.
2. Enable WebXR in Safari Settings -> Advanced -> Feature Flags.
3. Open project page and tap **"ENTER VR MODE"**.

### 3. Desktop & Mobile Fallback Mode
If accessed on a PC or smartphone:
- Drag with mouse or touch to rotate the 3D model.
- Scroll wheel or pinch to zoom.
- Toggle wireframe or auto-rotate controls.
