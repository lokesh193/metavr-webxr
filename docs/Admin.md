# Admin Guide

## Moderation & Admin Control Panel

Access the Admin Panel at `/admin` (requires account with `role: "ADMIN"`).

### Capabilities
- **Platform Telemetry**: Inspect active WebXR project count, registered users, server uptime, and memory consumption.
- **Project Moderation**: Delete inappropriate 3D assets or Unity builds.
- **Audit Logs**: Review automated virus scanning reports and compression logs.
